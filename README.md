# Hinggo_DeadlineDataFormatter
A simple beginner Python program that asks for an event title, year, month, and day, then prints a clean, readable formatted deadline including the full month name and weekday.

## Project Goal
Create a small date‑formatting tool for class activities.
The program receives event details and displays a nicely formatted deadline that classmates can easily read.

## Inputs
- Event title
- Year
- Month
- Day

## Outputs
- Event title in uppercase
- Formatted full date (Example: June 3, 2026)
- Separate Year, Month, and Day
- Weekday of the given date

## Technologies Used
- Python 3
- datetime module for date and weekday formatting
